# TFT Companion

Canal público de instaladores e atualizações do aplicativo desktop para Windows.

[Baixar a versão mais recente](https://github.com/devlela/tft-companion-updates/releases/latest)

Feche a versão portátil anterior e execute o instalador uma vez. As próximas versões são consultadas ao abrir o app e a cada 30 minutos enquanto aberto. O download é automático; a instalação começa quando você escolher reiniciar.

O aplicativo inclui laboratório offline, guia sobreposto e coleta local de uso e cenários. O catálogo incluído é uma demonstração sintética. Integrações com partidas ao vivo e MetaTFT ainda não estão conectadas, e não há modelo de machine learning treinado.

Este repositório contém os instaladores e metadados públicos de atualização. Seus cenários e registros pessoais permanecem no computador e não são publicados aqui.
